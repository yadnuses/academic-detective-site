# Fan Family 封面交通工具图片生成需求文档

## 一、项目背景

封面参考 `chartogne-taillet.com` 的仪式感入场：点击进入后，用户通过横向滚动穿越一条“交通工具变迁”时间线，象征范氏家族从 1946 到 2020 年的迁徙史。

目前页面已开发完成，使用 SVG 线条占位图。本文件用于生成 6 张正式的交通工具插画，替换占位图。

目标页面：
`/Users/xiaoy/Downloads/project 4/FanFamily_analysis/visual_report/index.html`

---

## 二、整体视觉风格

| 项目 | 要求 |
|------|------|
| **风格** | 线条漫画 / 手绘线稿 / 复古工程图感，类似木刻版画或旧报纸插图 |
| **线条颜色** | 深棕色 `#2c241b`，单色线稿 |
| **填充** | 无填充，或仅使用极浅的米色/纸色点缀 |
| **阴影** | 无渐变、无投影、无写实光影 |
| **背景** | **透明背景（PNG）**，方便叠加到网页米色纸纹上 |
| **构图** | 横向 16:9，主体居中，四周留出安全边距 |
| **推荐尺寸** | 1600 × 900 px（最小不低于 1200 × 675 px） |
| **格式** | PNG（透明底），如有条件可额外提供 SVG 矢量稿 |
| **气质** | 克制、安静、有年代感，不过度卡通，也不过度写实 |

### 页面底色参考

- 背景色：`#f7f3ec`（暖米色）
- 强调色：`#a12d2d`（朱红，用于进度条和点缀，不建议大面积出现在插画中）

**生成提示词：**

```text
线条漫画风格，透明背景，深棕色 (#2c241b) 手绘线条，无填充、无阴影、无渐变。
一艘民国时期的木壳江轮侧面，船身有简单的舷窗和一层甲板，烟囱冒出细细一缕烟。
甲板栏杆后站着一个抱书、提布包的少女小剪影，象征 16 岁离家出走的范瑶珠。
船只占画面主体，横向 16:9 构图，四周留出透明边距，画面干净简洁。
```
